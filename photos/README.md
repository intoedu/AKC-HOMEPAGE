## 올리는 방법

폴더 링크를 눌러 **들어간 뒤** 파일을 끌어다 놓으세요.
파일 이름에 `/` 를 쓰면 GitHub 에서 `:` 로 바뀌어 폴더로 인식되지 않습니다.

- https://github.com/intoedu/AKC-HOMEPAGE/upload/main/photos/inbox

## 사진 고르는 기준

- **쓰는 것**: 정면을 보는 얼굴, 웃는 표정, 활동 중인 모습, 평범한 옷차림
- **쓰지 않는 것**: 우는 사진, 고개 숙인 사진, 뒷모습, 감정을 자극하려는 구도

캠프 사진첩에서 가장 흔한 것이 우는 아이들 사진인데, 현장에서는 은혜의
증거지만 홈페이지에 걸리는 순간 아이를 감정의 소재로 쓰는 것이 됩니다.
부모 입장에서도 불편하게 읽힙니다.
