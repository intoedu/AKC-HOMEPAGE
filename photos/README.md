# 사진 넣는 곳

파일을 아래 자리에 두기만 하면 홈페이지에 자동으로 표시됩니다.
파일이 없는 동안에는 "사진을 넣어주세요" 안내가 대신 보입니다.

## 이름을 정하지 않은 사진

**`photos/inbox/` 에 그냥 다 올려주세요.** 파일명은 아무거나 괜찮습니다
(카메라가 붙인 `IMG_1234.jpg` 그대로도 됩니다).
어느 자리에 쓸지는 사진을 보고 정한 뒤 이름을 바꿔 배치합니다.
배치가 끝나면 `inbox` 는 비웁니다.

## 사진 고르는 기준

- **쓰는 것**: 정면을 보는 얼굴, 웃는 표정, 활동 중인 모습, 평범한 옷차림
- **쓰지 않는 것**: 우는 사진, 고개 숙인 사진, 뒷모습, 감정을 자극하려는 구도

캠프 사진첩에서 가장 흔한 것이 우는 아이들 사진인데, 현장에서는 은혜의
증거지만 홈페이지에 걸리는 순간 아이를 감정의 소재로 쓰는 것이 됩니다.
부모 입장에서도 불편하게 읽힙니다.
