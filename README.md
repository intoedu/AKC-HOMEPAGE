# AKC-HOMEPAGE (이전됨)

AKC 홈페이지는 **https://intoedu.github.io/AKC/** 하나로 합쳤습니다. (2026. 10.)

- 소스와 수정은 `intoedu/AKC` 저장소에서 합니다.
- 이 저장소는 예전 주소(https://intoedu.github.io/AKC-HOMEPAGE/)로 들어온 방문자를 새 주소로 보내는 역할만 합니다.
  - `index.html` — 새 주소로 바로 이동. 예전 링크의 `#schedule` 같은 위치는 새 사이트의 해당 페이지로 연결
  - `404.html` — 예전 사진 주소 등 다른 경로로 들어와도 새 주소로 이동
  - `assets/` — 예전에 카카오톡으로 공유된 미리보기 이미지가 깨지지 않도록 남겨 둔 파일
- 통합 전 사이트(한 페이지 버전)는 이 저장소의 git 기록에 그대로 남아 있습니다.
